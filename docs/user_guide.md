# 维拓校务管理平台 · 操作指南

本指南面向校区管理员和教务人员，按日常使用顺序说明各模块的操作方法。界面文案以当前版本为准。

## 1. 登录与全局操作

### 1.1 登录

- 打开系统后进入登录页，输入用户名与密码。
- 账号由超级管理员在「用户管理」中创建，系统不提供自助找回密码。
- 未分配任何校区的账号无法进入后台，登录后会被退回登录页并提示联系管理员。
- 特例：当系统内一个校区都没有时（初始部署或校区刚被全部删除），已登录账号会进入引导模式，被直接带到「学校管理」创建校区；创建后到「学期管理」为该校区创建学期，即恢复正常权限校验。

### 1.2 新手使用指引

- 首次登录进入首页时，会自动弹出「新手使用指引」，按顺序介绍从基础配置到报表续报的流程。
- 每一步会根据当前数据标记「已完成 / 待完成」：
  1. 确认校区与学期（还没有学期时，先到「学期管理」创建）
  2. 配置年级科目与课次（仅超级管理员可见）
  3. 准备教师与学员
  4. 开班
  5. 开课与考勤
  6. 看报表、做续报（参考项，不计完成状态）
- 可以用「上一步 / 下一步」浏览；点「跳过」或「开始使用」后不再自动弹出。
- 之后想再看，点首页右上角「使用指引」，或首页快捷操作里的「使用指引」。
- 是否已读按账号记录；新账号首次登录会重新出现。

### 1.3 顶栏：切换校区与学期

- 顶栏左侧显示当前校区、当前学期，点击可切换。
- 切换后，学员、班级、报表等页面都会按新的校区 / 学期重新取数。
- 进入某个班级详情前，请先确认顶栏学期与该班级所属学期一致，否则会出现打不开的情况。
- 右侧用户菜单包含「注销登录」。

### 1.4 侧边栏

- 功能入口：首页概览、班级管理、班级预留报表、年级报表、学员管理、教师管理。
- 超级管理员额外看到「系统设置」：学校管理、学期管理、年级科目管理、日校管理、用户管理。
- 侧边栏可以收起为图标条，点击左上角的收起按钮即可切换；刷新后会记住状态。

### 1.5 角色差异

| 角色 | 能做什么 |
| --- | --- |
| 超级管理员（admin） | 全部菜单；维护学校、校区、学期、年级科目、用户与校区授权 |
| 管理员（manager） | 只能看到被授权校区、被授权年级的数据；侧边栏不显示系统设置入口 |

### 1.6 首页概览

登录后默认进入首页概览：

- 四张概览卡：学员总数、在班学员、本学期班级、教师。
- 课次进度：本学期已开 / 总课次，以及今日课次、待开课次、待入班、本学期新增。
- 快捷操作：班级管理、学员管理、班级预留报表、复制班级、教师管理、操作指南、使用指引。
- 最近班级与最近学员：可快速进入近期班级，或查看最近建档的学员。
- 所有数字与列表都按顶栏当前校区、学期和账号授权年级统计；切换校区/学期后自动刷新。

## 2. 学员管理

入口：侧边栏「学员管理」。

### 2.1 快速筛选

页面顶部有四张概览卡：

- **全部**：当前校区、当前授权年级下的全部学员。
- **在班学员**：当前学期至少有一个在班班级的学员。
- **有退课**：当前学期存在退课记录的学员。
- **未入班**：当前学期还没有任何班级记录的学员。

点击卡片即可筛选，卡片高亮表示当前生效。再次点击「全部」或使用筛选栏的「重置」可恢复。

### 2.2 搜索与筛选

筛选栏支持：

- 姓名关键字搜索。
- 年级筛选（仅显示当前账号被授权的年级）。
- 「查找」提交；「重置」清空搜索与年级条件。

翻页时会保留当前筛选条件。列表底部可以切换每页条数（20 / 30 / 50 / 100），切换后回到第 1 页并保留筛选条件。

### 2.3 学员详情与编辑

每行右侧点击「详情」，详情与编辑合并在同一个抽屉里：

- **学员档案**：姓名、年级、性别、入学学期、生日、电话、日校、日校班级、分层、监护人、推荐人、家庭住址与备注均可直接修改，点「保存」生效。
- **班级信息**：合并展示当前学期与历史学期的班级，按学期倒序排列，含班级名、科目、教师、在班状态（在班 / 退课 / 转出 / 已移出）和考勤汇总（考勤次数、出勤、请假、缺课、退转、转入）。
- **当前学期**会以高亮底色和「当前学期」徽章标出，向上/向下追溯历史时更容易定位。
- 历史记录只展示已开始的学期，未来学期预排的班级不会混入。

### 2.4 新增 / 编辑学员

- 页头「添加学员」打开新建抽屉。
- 修改学员信息、增删监护人都在「详情」抽屉中完成；抽屉下半部分同时展示班级信息与考勤汇总。
- 「推荐人」输入姓名后搜索本校区学员（可跨年级），选中后以标签展示，点「×」可清除；留空表示没有推荐人。列表不会展示全部学员，需先输入姓名搜索。
- 学员归属当前校区，不能在这里跨校区移动。
- 学员档案可填写「家庭住址」（选填），会显示在详情抽屉里。
- 「删除」为软删除：学员不再出现在学员列表与选班名单中，历史班级、考勤和推荐关系保留；在顶部「已删除」卡片中查看并「恢复」。
- 监护人可登记多个：姓名选填、电话必填，另有关系与职业两个选填字段；只有电话也能建档。
- 「日校」右侧有「快速添加」（仅超级管理员）：填写名称即可新增日校并自动选中，不需要先去日校管理。

### 2.5 同名学员

- 系统允许存在同名学员，不以姓名作为唯一标识。
- 同校区同名学员会按建档顺序自动编号（1、2、3…）；第二个起在姓名后显示「序号 2」「序号 3」。
- 新增、编辑或导入时，姓名结尾输入数字会直接作为序号：「张三2」存为姓名「张三」、序号 2；该序号已被同名学员占用时自动顺延到下一个空闲序号。
- 编辑学员时可直接修改「重名序号」（正整数，新建时不显示，由系统自动分配）；序号不能与同校区同名的其他学员重复，冲突会提示保存失败。要互换两位同名学员的序号，可先把其中一位改成一个没人用的序号。
- 推荐人搜索、班级学员选择器、考勤表、考勤导出和班级预留报表都会带序号；第一个同名学员默认显示原名，后续同名学员显示序号。
- 删除学员、查看考勤或选择推荐人时，请结合序号确认具体是哪一位。

### 2.6 批量导入学员

- 页头「批量导入」打开导入抽屉。
- 支持上传 `.xlsx` 文件，或直接在文本框中粘贴数据；两者同时提供时以 Excel 文件为准。
- 抽屉内可点「下载导入模板」，模板包含表头、填写说明和示例数据，按模板填写后上传即可。
- Excel 首行可以是表头，也可以直接从数据行开始。列顺序：前 9 列为学员信息（姓名、性别、生日、年级、层级、入学学期、日校、日校班级、家庭住址），之后每位监护人 4 列（姓名、电话、关系、职业）；模板默认列了 2 位监护人。
- 粘贴文本时每行一个学员，字段用英文逗号分隔：姓名、性别、生日、年级 level、层级、入学学期、日校，可再追加日校班级、家庭住址，之后每 4 列一位监护人（姓名、电话、关系、职业），可写多名。
  示例：`张三,男,2013-05-01,7,提高,2026秋季,一中,初三(2)班,和平路 88 号,张建国,13800000000,父亲,工程师,李梅,13900000000,母亲,医生`
- 年级填 7 / 8 / 9 这类 level，按**本校区**的年级字典匹配；日校必须是当前校区已有名称；入学学期填**本校区**已有的学期名称，可留空，匹配不到时留空建档；性别支持男 / 女或 male / female。
- 日校班级为自由文本（如 初三(2)班），选填；家庭住址为选填，会写入学员档案并在详情抽屉展示。
- 监护人按组填写，可写多名：填写电话即创建监护人，姓名、关系、职业都可以留空；整组电话留空则该组忽略。
- 去重规则：同一校区下**姓名 + 生日**相同视为同一学员，跳过该行；生日为空时按**姓名 + 年级**判断。年级、日校、入学学期、性别等变化不会重复建档。
- 年级、日校不匹配或年级不在授权范围内的行会跳过，导入结果会提示新增与未导入行数，并逐行列出未导入学员的行号、姓名与原因（如年级 / 日校不存在、未授权、已存在）。
- 整批导入在一个事务内完成：任一行写入失败会全部回滚，不会只导入一部分。
- 导入只创建学员档案（及可选监护人），不会自动加入班级。

### 2.7 批量升年级

- 勾选列表左侧的复选框，表头复选框可全选 / 取消全选当前页。
- 顶部会显示已选人数，点击「批量升年级」并确认后，所选学员按当前年级 +1 更新。
- 只更新学员年级，不会调整已入班记录；没有更高年级、或下一年级不在当前账号授权范围内的学员会被跳过，提示中会说明人数。
- 如果当前按年级筛选，升级后的学员可能从当前列表消失，属于正常现象。

### 2.8 推荐看板

入口：侧边栏「推荐看板」。

- 顶部汇总推荐总数、推荐人数、本月新增与人均推荐。
- 「推荐排行」按推荐人数从高到低展示前 10 名推荐人。
- 「被推荐学员年级分布」展示各年级被推荐的学员数。
- 「推荐明细」按时间倒序列出被推荐学员、推荐人及推荐时间，支持页码跳转与每页条数（20 / 30 / 50 / 100）切换。明细右上角的搜索框可按人名模糊搜索，推荐人或被推荐学员任一方姓名命中即列出该条；人名搜索只筛选明细列表及其导出，不影响上方汇总卡片、排行与年级分布。
- 可按「推荐人年级」「时间范围（本月 / 近3个月 / 近12个月）」筛选，筛选联动全部汇总、排行、分布与明细；统计范围仅包含当前校区、当前账号授权年级内的推荐关系。
- 右上角「导出报表」下载 xlsx：「推荐汇总」页含指标、推荐排行与年级分布（按年级 / 时间口径，不含人名搜索），「推荐明细」页含当前筛选（含人名搜索）下的全部推荐记录（不分页），导出内容与页面一致。

## 3. 教师管理

入口：侧边栏「教师管理」。

- 可按姓名搜索、按科目筛选，筛选状态在翻页后保留。
- 「创建教师」填写教师名、电话、科目；科目决定该教师能带哪些班级。
- 「导入」可粘贴名单批量建档：每行「科目,姓名,电话」，支持从 Excel 直接粘贴；科目不存在或同科目同名已存在的行会跳过。
- 每行「编辑」可修改教师信息。
- 「存档」用于离职教师：存档后不会出现在开班 / 复制班级的教师选项里，历史班级与考勤不受影响；通过状态筛选「已存档 / 全部」查看，点「恢复」可重新启用。
- 教师有归属校区与科目；开班时在教师框输入姓名或科目搜索并点选（支持方向键 + 回车），科目会自动带出。

## 4. 班级管理

入口：侧边栏「班级管理」。

### 4.1 总览

- 顶部四张卡：班级数、在班学员、已开课次 / 总课次、待开课次。
- 可按学员姓名、年级、科目、教师、阶段、班型筛选；筛选后统计卡与班级列表同步更新，点「重置」恢复全部。学员姓名支持模糊匹配，只列出包含该姓名学员的班级。
- 班级按年级分组，每个班一张卡片，显示班级名、科目、教师、在班人数、预留率和开课进度。
- 同一年级、科目下按「阶段 → 班型 → 序号」排列：一期在前、二期在后，班型按提高 / 精英 / 创新 / 兴趣 / 超常排列。
- 点击任意班级卡片进入该班考勤详情。

### 4.2 开班

页头「开班」打开创建抽屉（班级考勤页右上角也提供「开班」，创建后直接进入新班级）：

1. 选择阶段（一阶段 / 二阶段）、班型、年级、教师、课次；班级序号由系统自动生成。年级与班型是点选按钮：年级只列出当前账号在本校区负责的年级，新建时默认选中序号最靠前的一个；班型默认提高班。阶段同样是点选按钮，默认第一阶段。
2. 科目由所选教师自动带出，不需要单独选择。
3. 班级序号在同一学期、年级、科目、班型内自动递增，并跳过含 4 的序号（4、14、24、40-49…）。
4. 学员名单有两种录入方式，二选一：「勾选学员」按姓名搜索勾选同年级学员；「粘贴名单」每行填「姓名,入班课次」，课次可省略（默认用上面的入班课次）。
5. 勾选模式下搜索不到学员时，直接在搜索框输入姓名并点「快速添加学员」：系统会按当前班级年级直接建档，创建后自动加入列表并勾选，不再弹窗。
6. 提交后系统会按课次自动生成课程；学员从各自的入班课次开始，之前课次补记为缺课；粘贴名单里没有档案的姓名会按本班年级自动建档，已在班或重复的行会跳过，提示里会显示加入、新建与跳过人数。

班级名称由「期次 + 年级 + 科目首字 + 班型首字 + 序号」组成，例如 `一期7数提1`、`二期7数提1`。同一学期的一阶段、二阶段可以重复使用班型与序号，自动序号也按阶段分别计算。

系统会自动避开已有序号；如果开班时组合仍有冲突，会提示班级已存在，可调整班型或年级后重试。

### 4.3 编辑班级

在班级详情页点击「班级详情」，可调整班型、教师、课次和班级序号；学员名单支持搜索勾选并指定入班课次。修改教师会同步更新班级科目。勾选列表只列出与本班同年级的学员；保存时若有学员年级与班级不符（例如名单是切换年级前勾选的），这些学员不会加入，提示里会显示「N 人因年级与班级不符未加入」。同一学期内每名学员同科目只能在一个班就读，若勾选的学员已在本学期同科目的其它班，则不会加入，提示里会显示「N 人因已在同学期同科目其他班未加入」；转班不受此限制。

- **序号**：可手动修改，输入时自动剔除含 4 的数字；同一学期、校区、年级、科目、班型、阶段下序号不可重复，冲突时会提示序号已存在。修改后班级名称同步更新。
- **课次**：调大会自动补齐缺少的课次，调小会删除多出的**未开课**课次；已有开课的课次不能减少（会提示当前已开课数量）。
- **年级**：班级已有学员（含已移出）时不可修改，避免在班学员与班级年级不一致；空班可以改。
- **阶段**：与年级相同，班级已有学员后不可修改；空班可在两个阶段之间调整，调整后班名与同阶段序号随之变化。
- **删除班级**：班级详情页右上角有「删除班级」，会连同该班的课次与学员报名记录一起删除，不可恢复；已有开课记录的班级不能删除（按钮置灰），以保留考勤历史。

### 4.4 导出考勤

- 总览页「导出考勤」：导出当前学期、当前校区全部班级的考勤。
- 一个班一个 Sheet，Sheet 名为「年级-班级名」，全部放在同一个 xlsx 文件里。
- 单个班级的导出在班级详情页点击「导出考勤」。

## 5. 班级详情与考勤

从班级管理卡片进入，页面由顶部操作区、左侧班级切换菜单和右侧考勤矩阵组成；矩阵上方是图例与常用操作工具栏。

### 5.1 班级切换菜单

- 只列出当前学期实际有班级的年级和科目。
- 年级、科目旁的数字是班级数；点击年级 / 科目可展开。
- 同一科目下按「阶段 → 班型 → 序号」排序：一期在前、二期在后，班型按提高 / 精英 / 创新 / 兴趣 / 超常排列。
- 当前班级高亮，对应年级和科目自动展开。
- 菜单支持吸顶，滚动查看长考勤表时仍可切换班级。

### 5.2 考勤矩阵

- 行是班级学员，列是课次；退课 / 转出的学员仍保留在列表中。
- 表格上方可按学员姓名搜索，实时过滤行并显示匹配人数；按 Esc 清空搜索。
- 表头显示「第 N 课」和开课日期；未开课的课次在表头标注「未开课」，表体用「—」占位。
- 已开课的课次显示该学员的考勤状态：`√` 正常、`补` 补课、`缺` 缺课、`事` 事假、`病` 病假、`退` 退课、`转` 转出、`入` 转入（由转出生成或手动标记，表示该课次学员尚未转入本班）。
- 矩阵上方工具栏提供状态图例，可直接对照缩写与含义。

### 5.3 开课与添加学员

在班级详情页打开「班级详情」抽屉，在「学员名单」区域添加学员：先选择入班课次，再搜索勾选同年级且尚未加入本班的学员；也可以切到「粘贴名单」，每行一位「姓名,入班课次」批量加入，没有档案的姓名会自动按本班年级建档。保存后学员从各自的入班课次开始加入，之前的课次补记为缺课，已开课的课次自动生成考勤。名单里没有需要的学员时，可在同一区域用「快速添加学员」直接建档。

考勤矩阵上方的工具栏：

- 开课需按课次顺序进行：选择「开课到 第 N 课」后点「批量开课」，把未开课的课次按顺序全部开完；只开下一节课时，直接选首个未开课的课次即可。
- 「开课日期」是首个未开课课次的日期（默认今天），「间隔天数」是相邻课次的间隔（默认 7 天，可填 0 表示同一天）：之后的课次日期按间隔依次累加，补录历史课时按实际排课填写。
- 开课后按填写日期生成考勤：在班学员为「正常」，已退课 / 转出的学员沿用其「退课」/「转出」状态。
- **修改已开课日期**：点击表头下课次下方的日期（如「03-01」）打开抽屉，改完保存即可。默认只改这一课；勾选「后续已开课课次按间隔顺延」后，后面已开课的课次会从新日期起按所填间隔逐课累加，抽屉下方会预览顺延后的起止日期。未开课的课次不受影响，考勤记录也不会变。
- 同一课次重复开课或多人同时开课不会重复生成考勤：已开课时提示「已开课，无需重复操作」。

### 5.4 修改考勤状态

点击学员当格的考勤徽章会展开操作卡；再次点击、点击空白处或按 Esc 关闭：

- 顶部显示学员、课次和当前状态。
- 考勤状态区：缺课 / 事假 / 病假 / 补课销假，缺课 / 事假 / 病假三个状态排在同一行。
- 退转区：退课 / 转出，与考勤状态用分隔线区分，避免误点。
- 事假 / 病假 / 缺课的学员同样可以标记「退课」或「转出」。
- 已退课的学员显示「重新加入」；已转出的学员不提供撤销操作。「补课销假」仅用于缺课 / 事假 / 病假。
- 缺课 / 事假 / 病假 / 补课销假可点「恢复正常」纠正误操作；退课可「重新加入」；转出不可撤销（手动标记的转出除外，见下）。
- **标记为转入 / 标记为转出**只在全部课次结课（都已有开课日期）后出现，用于结课后修正考勤表；学期进行中不显示这两个入口。
- **标记为转入**：学员实际是从后面的课次才进入本班时，可在其入班前已开课的课次点「标记为转入」，该格显示「入」且不计入出勤。只改这一格，不改班级名单里的在班状态，也不影响其它课次；手动标记的转入可再点「恢复正常」撤销。由「转出」自动生成的转入记录仍然只读。
- **标记为转出**：学员本课次已不在本班就读、但报名仍在班时（例如还没走转出流程），可在该格点「标记为转出」，该格显示「转」且不计入出勤。同样只改这一格，不改班级名单里的在班状态，也不影响其它课次；手动标记的转出可再点「恢复正常」撤销。由「转出」抽屉生成的转出记录仍然不可撤销。

**转出到其它班：**

- 当同校区、同学期、同年级还有其它班级时，点「转出」会打开右侧抽屉，选择目标班级后确认。
- 抽屉会自动隐藏该学员已在班或退课的班级，已转出的班级会保留供转回；支持按科目、班型筛选，科目默认选中当前班级的科目。目标班按阶段 → 班型 → 序号排列。
- 确认后原班保留该学员并标记为「转出」，同时把学员加入目标班；目标班该学员入班前的考勤格显示「入」，点开可查看转入详情（由哪个班转入、第几课起在本班上课）。
- 入班课次按原班转出课次对齐：从转出课次的下一课起在目标班上课（不早于目标班首个未开课课次）；入班课次之前的课次统一标记为只读的「转入」（表示学员当时尚未在本班就读），不论这些课次是转入前还是转入后补开的，都不再沿用原班考勤，原班的真实考勤原样保留在原班。
- 转出必须选择目标班级：若同年级暂无可转入的班级，「转出」按钮不可用；仅离开班级请使用「退课」。
- 目标班课程已全部开始时无法转入，避免在已结课的课次上凭空生成考勤。
- 非法状态或已不可变更的状态（例如在班学员点「重新加入」）不会写入数据库，页面会提示当前状态无法变更。

**撤销退课：**

- 班级详情底部「转出 / 退课学员」会列出当前不在班的学员及其离开的课次。
- 退课学员点「撤销」可恢复为在班，并把最近一整段连续退课的考勤恢复为正常。
- 转出不可撤销：转出记录只读，名单中会提示学员已转入哪个班。

**转出后回原班：**

- 到学员当前所在的班级（转入班），在考勤格点「转出」，抽屉中选择原班作为目标班即可转回。
- 原班恢复为在班；原班此前已开课、入班课次之前的课次会标记为「转入（来自转入班）」，原来的「转出」记录被改为「转入」，而原班此前的真实考勤（正常 / 缺课 / 请假等）保持不变。
- 转入班保留该学员并标记为「转出」。
- 原班课程已全部开课时无法转回（目标班没有未开课课次）。

**级联规则：**

- 标记「退课」或「转出」后，学员的班级状态变为退课 / 转出，并继续保留在班级列表中。
- 该课次之后**已开课**的课次会立即同步为该状态；**未开课**的课次在开课时沿用退课 / 转出状态生成考勤。
- 之后在考勤格点「重新加入」：仅退课可用——学员恢复为在班，当前课次及之后已开课的退课考勤恢复为正常，之前缺的课保留退课记录；未开课课次开课时按在班生成。转出不能这样撤销。
- 班级详情底部「撤销」则回滚最近一整段连续退课的已开课课次。转出需到转入班反向转出回原班。
- 请假、缺课、补课等只影响当前课次。

### 5.5 移出学员

- 考勤表首列勾选要移出的学员（表头可全选，搜索过滤后全选只作用于可见行），点工具栏「移出」弹出确认窗口，窗口中列出已勾选的学员。
- 确认后学员不再出现在考勤表，但历史考勤会保留。
- 班级详情下方「已移出学员」中可查看并点「恢复」重新加入。
- 关闭弹窗不会移出任何学员。

### 5.6 预留下学期

入口：班级考勤表勾选学员后点工具栏「预留」。

- 考勤表首列勾选要预留的在班学员（表头可全选，搜索过滤后全选只作用于可见行），点「预留」弹出预留窗口，窗口中只列出已勾选的学员。
- 目标年级：可选现年级或下一个年级；班型可以不同，教师可以不选（「暂不指定」），留到预留表生成分班时再定。
- 已预留管理：考勤表学员名旁有一个信息图标（蓝色=已预留、绿色=已生成班级、灰色=已在下学期同科目班级就读），鼠标悬停弹出卡片，展示目标年级 / 班型 / 教师等 badge；已预留的可在卡片内直接修改或取消预留，已生成班级的只读（需到对应班级中调整）。预留窗口下方「已预留」也列出全部预留供集中查看。
- 预留只登记到预留表，不会直接加入下学期班级，也不会修改学员当前年级；升年级请在学员管理中使用批量升年级。
- 确认后可在侧边栏「预留表」中按分组生成下学期班级，见 5.7。
- 若下学期尚未创建，需先到「学期管理」创建学期（见 9.1）。

### 5.7 预留表

入口：侧边栏「预留表」。一行一名预留学员，只列出目标学期为当前所选学期的预留记录，作为下学期的分班依据；要看其它学期的预留，先用顶栏切换学期。

- 每行显示学员（现年级）、源学期（来源班级所在学期）、目标年级、科目、班型与阶段、教师和状态；教师未指定时显示「待定」，状态为「待分班」或「已生成 · 班级名」。
- 筛选：学员姓名、年级、科目、班型、教师、预留状态全部同栏显示；可组合使用，「重置」清空条件。
- 批量进班：勾选若干待分班学员（表头可全选）后点「批量进班」，右侧抽屉里二选一：
  - 按分组生成新班级：同一分组（同学期、年级、科目、班型、阶段、教师）只建一个新班，且仅加入勾选的学员；抽屉里逐个分组列出选中的学员姓名，并可调整新班级的年级、班型、阶段、教师和课次，未指定教师（或教师已存档）的分组必须先选教师。
  - 加入已有班级：把勾选的学员加入目标学期已有的同科目班级；要求所选学员属于同一目标学期、科目与年级，且与所选班级一致（目标年级不同的班级不能加入）。学员现年级须与班级年级一致才能进班，未升级到目标年级的学员会被跳过。
- 分班不会修改学员年级：未升级的学员会被跳过（预留仍为「待分班」，升级后可再次进班）；整组都未升级时不会生成空班级，会提示先到学员管理批量升年级。
- 已生成的分组不会重复生成；想调整个别学员，生成后在班级详情中处理。
- 预留表只作为分班依据：班级预留报表的「预留」仍按下学期同科目班的实际出勤计算，未预留原因里会把已登记预留的学员标为「已登记预留，待分班」。

### 5.8 空班级

新开班或学员全部移出后，表格下方会提示可通过页头的「添加学员」导入。

## 6. 班级预留报表

入口：侧边栏「班级预留报表」。

### 6.1 指标口径

| 指标 | 口径 |
| --- | --- |
| 预留 | 当前在班学员中，已报下学期同科目班级、且在该班实际上课达到阈值的学员（达标后在下学期班级退课 / 转出的仍计入） |
| 未预留 | 当前在班学员中，未报下学期同科目班级或上课次数未达阈值的学员（与预留互补） |

分母都是当前在班学员数。页面顶部的「口径」说明条也提供同样的解释。

「预留」的上课次数阈值可在页头「预留设置」中调整（按校区生效，默认 4 次），只统计「正常 / 补课」出勤；下学期还没开课时，预留率会是 0。

### 6.2 汇总卡

- 统计班级数、在班学员人次。
- 平均预留率。

### 6.3 明细表

- 一行一个班级，显示所在学期、年级、科目、教师、班型、班级、在班人数。
- 预留列同时显示百分比和「人数 / 在班人数」。
- 支持按学期、年级、科目、教师、班型筛选；筛选条件在提交后保留，导出时也会带上。

### 6.4 查看班级详情

每行「详情」打开抽屉：

- 顶部指标条展示在班、预留、未预留的人数与占比。
- 未预留学员单独成卡片，排在构成之前，包含人数、原因和名单，便于优先跟进续报。
- 学员构成：预留一组，列出学员姓名和来源说明（下学期名称、对应班级/教师与已上课次数）。
- 在班名单：未预留学员排在前面，并用黄色标签标注。
- 名单较长时可在抽屉内滚动。

### 6.5 导出报表

页头「导出报表」会导出当前筛选结果，包含两个 Sheet：

- **班级预留报表**：汇总表，含人数、预留数量与百分比、筛选条件。
- **学员明细**：一行一个学员，含学期、年级、班级、科目、教师、类型（预留）、姓名和说明。

## 7. 年级报表

入口：侧边栏「年级报表」。

按学期分组、按年级统计学员来源构成，默认展示全部学期，也可在页面顶部按学期筛选。

### 7.1 指标口径

| 指标 | 口径 |
| --- | --- |
| 新增 | 本学期在班学员中，更早学期从未有入班记录的学员 |
| 拓科 | 本学期在班学员中，上学期有入班记录，且本学期有上学期没学过的科目（延续原科目加新科目、或直接换科都算） |
| 回流 | 本学期在班学员中，上学期没有入班记录、但更早学期有入班记录的学员（隔一个或多个学期重新入班都算） |

三项互斥；不属于任何一项的为「延续」学员（只在名单标签中显示）。入班记录只统计未退班 / 未被移出的在班报名。分母为该学期该年级的在班学员数；学员同时在两个年级上课时，会在两行各计一次（人次口径）。

### 7.2 汇总卡与明细表

- 汇总卡：覆盖学期数与在班 / 新增 / 拓科 / 回流人次合计。
- 明细表按学期分组，每组内一行一个年级，组尾有「小计」行；三个指标列同时显示百分比和「人数 / 在班人数」。

### 7.3 查看详情

每行「详情」打开抽屉：顶部为在班 / 新增 / 拓科 / 回流指标卡；学员构成按三类分别列出姓名与说明（新增显示入学学期与日校、拓科显示上学期科目、延续与新增科目（换科的没有「延续」）、回流显示最近一次入班的学期与科目）；在班名单用标签标注每位学员的类别。

### 7.4 导出报表

页头「导出报表」按当前学期筛选导出 xlsx，包含两个 Sheet：

- **年级报表**：一行一个学期×年级，含在班、新增 / 拓科 / 回流人数与百分比，每学期附小计行。
- **学员明细**：一行一个学员，含学期、年级、类型（新增 / 拓科 / 回流）、姓名和说明。

## 8. 复制班级

入口：班级管理页 / 班级预留报表页的「复制班级」；班级详情页的「复制」可打开复制抽屉。

### 8.1 从班级详情复制

班级详情页头「复制」会打开与复制页相同的抽屉，目标学期默认为下个学期：

- 可调整班型、序号、年级、教师、课次和学员，再提交。
- 默认勾选当前班在班学员，也可搜索同年级其他学员一并带入。
- 提交后回到当前班级页；新班级在目标学期生成，学员一并加入。
- 目标班生成后，班级预留报表的「预留」和班级卡片的预留率会同步更新。
- 若下学期尚未创建，「复制」按钮置灰，需先在「学期管理」创建学期。

### 8.2 选择目标学期

- 页头「目标学期」可选当前学期及其之后的学期。
- 目标为**当前学期**：列表来源是目标之前的历史学期。
- 目标为**未来学期**：列表来源包含历史学期和**当前学期**，可把本学期班级复制到新学期。
- 复制后的班级归属所选目标学期和当前校区。
- 若要复制到新学期，需先在「学期管理」中创建好目标学期。

### 8.3 查看详情

每行「详情」可查看来源班级的学期、班级名、年级、科目、教师、班型、序号、课次数、开课进度、在班与名单人数，以及学员名单。

### 8.4 执行复制

1. 点击某行的「复制」。
2. 抽屉会预填来源班级的班型、序号、年级、教师和课次，并列出源班学员供勾选。
3. 可以调整目标班级信息；学员名单是搜索多选，默认勾选源班在班学员，可搜索并勾选同年级其他学员一并带入，退课/转出默认不选。只加入与目标年级一致的学员。
4. 点击「复制到 <目标学期>」。

复制到当前学期后会跳到新班级详情；复制到未来学期后会回到复制页并保留目标学期（从班级详情页发起的复制会回到当前班级页）。若目标学期已存在相同组合，会提示失败，需要调整序号或班型。未来学期的班级需要先把顶栏学期切换到该学期，才能进入班级详情。

> 复制会重新生成课次和报名关系，不会带入来源班级的历史考勤。

## 9. 学校管理

仅超级管理员可见。入口：系统设置 → 学校管理。

本页只维护学校名称与校区；学期、年级科目、日校都在系统设置下的独立菜单中维护。

> 当系统内没有任何校区时（初始部署或校区被全部删除），任意已登录账号都会被引导到本页，可在此创建第一个校区；创建后当前账号自动获得该校区超级管理员权限，其余页面恢复权限校验。接着请到「学期管理」为新校区创建学期。

- **学校名称**：修改后保存。
- **校区管理**：新增 / 删除校区；校区是学员、教师、班级以及学期、年级科目字典的归属单位，各校区数据完全隔离。删除校区会连同该校区下所有学期、年级科目配置、学员、教师、日校、班级、课次、考勤与预留数据一并删除，保存后不可恢复，请谨慎操作。
- **学期**：已独立为「学期管理」菜单，见下方 9.1；学校页面不再维护学期。
- **年级科目**：已独立为系统设置下的单独菜单，见下方 9.2；学校配置抽屉内不再维护。
- 用户与校区的授权已移到「用户管理」，学校页面不再维护授权。
- 新增校区保存后，系统会自动为当前账号开通该校区（超级管理员）；新校区还没有自己的年级，年级范围暂时为空，创建年级后请到「用户管理」勾选。顶栏的校区切换菜单里即可看到新校区；其他账号需要到「用户管理」单独授权。

### 9.1 学期管理

仅超级管理员可见。入口：系统设置 → 学期管理（引导模式下不显示，先在学校管理创建校区）。

学期按**校区**独立维护：切换顶栏校区后，各校区分别管理自己的学期，互不影响。

- 列表按序号（`seq`）排列，显示每个学期的名称、序号和该学期下的班级数。
- 字段：**名称**、**序号**（同一校区内不可重复）、**设为当前学期**。
- **当前学期**每个校区只有一个：用于顶栏默认学期、历史 / 下学期判断与报表口径；勾选某个学期为当前学期后，同校区其它学期自动取消标记。
- **删除学期**：会连同该学期下的所有班级、课次、考勤与预留记录一并删除，学员的入学学期会被清空；删除不可恢复，页面会弹出确认提示，请谨慎操作。
- 删除的是当前学期时，系统会自动把序号最小的学期设为当前学期。
- 校区还没有任何学期时，访问学员、班级等依赖学期的页面会被引导到本页（超级管理员）或返回首页并提示联系管理员（其他角色），创建首个学期后即恢复正常。

### 9.2 年级科目管理

仅超级管理员可见。入口：系统设置 → 年级科目管理。

组合与课次按**当前校区、当前学期**分别维护：切换顶栏校区或学期后，分别为各校区各学期单独启用组合和设置课次。

- 页面以矩阵展示本学期开设的年级与科目组合：行为年级、列为科目，勾选表示该组合已启用。
- 勾选或取消后点「保存配置」，系统按差集增量启用 / 移除组合，不需要逐条维护。
- 学员筛选、开班、教师科目、报表筛选都以这里启用的组合为准。
- 新建的年级会自动追加到本校区所有超级管理员的授权年级；其他用户的授权年级请在「用户管理」中勾选（只能勾选该校区自己的年级）。
- 已有班级的组合会被锁定并标出班级数，不能取消；需先移除相关班级或课次后再操作。
- 保存时会提示新增 / 移除了多少组合，以及多少个组合因已有班级而未取消。

矩阵下方「课次设置」列出本学期已启用的组合，可逐个设置课次并随「保存配置」一起提交：

- 每个学期单独设置，新学期需要重新配置。
- 开班选择年级和教师后，会自动带出该年级 + 科目在本学期配置的课次，仍可手动调整；切换到未配置的组合时会清空课次，避免沿用上一个组合的值。

矩阵下方还有两份**校区字典**（只影响当前校区，仅超级管理员可维护）：

- **年级字典**：年级序号与名称，同一校区内序号、名称都不能重复。被学员、班级、年级科目组合或用户年级授权使用的年级不能删除。
- **科目字典**：科目编码与名称，同一校区内编码、名称都不能重复。被教师、班级或年级科目组合使用的科目不能删除。
- 字典按校区独立，切换顶栏校区后请分别维护；组合矩阵只维护当前校区当前学期。

### 9.3 日校管理

仅超级管理员可见。入口：系统设置 → 日校管理。

- 日校按**当前校区**维护，切换顶栏校区后分别管理。
- 「新增日校」填写名称即可；同一校区内名称不能重复，不同校区可以同名。
- 「导入」可粘贴名单批量新增：每行一个名称，支持从 Excel 直接粘贴；名称为空或已存在的行会跳过。
- 列表显示每个日校下的学员数；学员档案、批量导入和报表里的「日校」都以此名单为准。
- 已有学员的日校不能删除，需先把这些学员改到其它日校或清空日校字段。

## 10. 用户管理

仅超级管理员可见。入口：系统设置 → 用户管理。

### 10.1 创建账号

- 页头「创建用户」，填写用户名和密码。
- 创建时可以直接在下方添加校区授权。

### 10.2 编辑账号

- 每行「编辑」打开抽屉。
- 密码留空表示不修改；填写则重置密码。
- 校区授权支持一个账号授权多个校区：
  - 选择校区。
  - 勾选该校区可管理的年级；留空会导致该账号在该校区看不到任何年级数据，建议至少选择一个年级。
  - 选择角色：超级管理员或管理员。
  - 点击「添加校区」可增加授权，已有授权可移除。
- 列表中会展示每个账号的校区、角色和年级范围；没有授权的账号显示「未授权」。

### 10.3 授权的影响

- 账号只能登录被授权的校区。
- 管理员的年级授权决定学员列表、开班年级、报表筛选等可见范围。
- 未授权账号登录后会被退回登录页，需要先补充授权。

## 11. 导出文件说明

| 导出 | 入口 | 文件内容 |
| --- | --- | --- |
| 单班考勤 | 班级详情 → 导出考勤 | 一个 Sheet：班级信息、图例、学员 × 课次考勤矩阵 |
| 全部班级考勤 | 班级管理 → 导出考勤 | 一个 xlsx，每个班一个 Sheet，按年级排序 |
| 班级预留报表 | 班级预留报表 → 导出报表 | 一个 xlsx，两个 Sheet：班级汇总、学员明细 |
| 年级报表 | 年级报表 → 导出报表 | 一个 xlsx，两个 Sheet：学期×年级汇总（含小计）、新增/拓科/回留学员明细 |

导出文件为 `.xlsx`，可直接用 Excel、WPS 或 Numbers 打开。表头已冻结，长表格可配合自动筛选使用。

## 12. 常见问题

**Q：登录后看不到学员 / 班级？**

先确认顶栏的校区和学期是否正确，再确认账号的年级授权是否包含目标年级。管理员只看到被授权年级的数据。

**Q：切换学期后某个班级打不开？**

班级详情按当前学期取数。请先把顶栏切到该班级所属学期再进入。

考勤标记、开课、移出学员、预留等操作同样只作用于当前学期的班级；补录历史学期的数据，请先切换顶栏学期再操作。

**Q：开班或修改序号提示「已存在该序号」？**

同一学期、同一阶段内的「校区 + 年级 + 科目 + 班型 + 序号」组合必须唯一；一阶段与二阶段之间可以重复。开班时序号自动递增、会避开已有序号；编辑班级时可手动改序号，若与同年级 / 科目 / 班型 / 阶段下的其它班级重复就会提示，改一个序号、或切换阶段、调整班型 / 年级后重试即可。

**Q：班级序号为什么自动跳过 4？**

系统约定用序号区分同科目班型的班级，数字 4 与班型编码/名称容易产生歧义，因此自动生成时会跳过含 4 的序号；编辑时手动修改序号，输入框也会自动剔除含 4 的数字。

**Q：预留为 0？**

- 预留为 0：下学期还没有同科目班级，或学员未排入下学期班级；只在预留表登记、尚未生成分班的学员不计入预留。

**Q：移出学员还能恢复吗？**

可以。移出不会删除历史考勤，班级详情下方「已移出学员」中可点「恢复」重新加入；再次通过「添加学员」加入同一班级也会自动恢复原记录。

**Q：退课 / 转出会影响后面的课次吗？**

会。标记后学员仍留在班级列表中，当前课次之后已开课的课次会立即同步为退课 / 转出，未开课课次在开课时也会沿用退课 / 转出状态。退课可在考勤格「重新加入」或班级底部「撤销」；转出不可撤销，要回原班需到转入班再「转出」并选择原班。

**Q：为什么导出报表和页面筛选不一致？**

报表导出会带上当前筛选条件（学期、年级、科目、教师、班型）。如果刚修改了筛选但未点击「筛选」，请先提交筛选再导出。

## 13. 新学期准备流程（推荐顺序）

1. **学期管理**：确认本校区的新学期已创建、`seq` 与「当前学期」标记正确；在「年级科目管理」确认新学期的组合与课次已配置。
2. **用户管理**：为新学期涉及的校区补充账号授权与年级范围。
3. **预留表 / 复制班级**：在「预留表」把上学期登记的预留学员按分组生成分班，或用「复制班级」整体复制到新学期，也可以直接「开班」。
4. **班级管理**：核对班级卡片上的人数、预留率与课次，必要时调整班级信息。
5. **班级详情**：开课、添加学员、按课次记录考勤。
6. **班级预留报表**：按学期 / 年级查看预留率，导出报表归档。
